## Selected work

### GW-Standalone (Sento)
Autonomous IoT gateway firmware in MicroPython for LoPy4 (ESP32). LoRa P2P, Wi-Fi AP, and cellular (Blues Notecard) uplinks; bidirectional LoRa protocol with auto-ACK; persistent flash buffer so no reading is lost offline; concurrent threads, on-device web dashboard, hardware auto-detection.

### OTA fleet platform (Sento)
Over-the-air firmware management. React + TypeScript console on a serverless AWS backend (Lambda, API Gateway, DynamoDB, S3); firmware distributed through short-lived pre-signed URLs with live update monitoring; an Amplify variant with Cognito and AppSync GraphQL; CI/CD through GitHub Actions.

### Harsh-environment IIoT hardware (2019–2024)
IPC-compliant PCBs, enclosures, solar telemetry, and chemical-dosing control cabinets for poultry, swine, and agro-industrial sites. FCC certification, MicroPython firmware with supervisor mechanisms, and the move from 3D printing to injection molding for LATAM, Caribbean, and US rollouts.
