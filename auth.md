# ddtdanilo.github.io auth.md

This site needs no authentication. Every resource is public, read-only, and anonymous.

- **Audience:** any AI agent or crawler.
- **Registration:** none. There is no registration or provisioning endpoint, and no accounts exist.
- **Supported methods:** anonymous access only. Send plain HTTPS GET requests without credentials.
- **Credential use:** not applicable. Do not send tokens, API keys, or cookies; the site ignores them.
- **Resources:** see https://ddtdanilo.github.io/llms.txt and https://ddtdanilo.github.io/.well-known/api-catalog.
- **Payments:** consulting sessions are paid on Stripe-hosted pages linked from https://ddtdanilo.github.io/consult.md. Agents must get the user's explicit confirmation before any payment step.
